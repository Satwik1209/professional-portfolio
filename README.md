# Chunduru Narasimha Satwik - Portfolio Website

Personal portfolio website showcasing software engineering, cyber security, cryptography, and machine learning projects.

## Tech Stack
* **HTML5 & Semantic Markup**
* **Tailwind CSS** (Modern utility-first styling with dark mode)
* **Lucide Icons**
* **Plus Jakarta Sans & JetBrains Mono Fonts**

## Deployment
Configured for instant, zero-config deployment on **Vercel** (`vercel.json`).
