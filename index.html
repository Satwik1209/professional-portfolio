ENTERPRISE ARCHITECTURE CASE STUDY

600+ Repository Cloud Migration & CI/CD Modernization

Australia & New Zealand Banking Group (ANZ)

The Operational Challenge

ANZ's engineering squads operated across legacy on-premises GitHub Enterprise Server (GHES) instances with fragmented deployment scripts (Codefresh, uDeploy) and manual validation gates. Transitioning 600+ repositories to GitHub Enterprise Cloud (GHEC) required strict zero-downtime cutovers, cryptographic commit DAG preservation, and immediate compliance with bank-wide DevSecOps governance.

01

Pre-Flight API Auditing

Programmed automated Bash and REST API crawlers to inventory repo sizes, LFS assets, branch protection rules, and webhook dependencies. Generated automated parity reports prior to migration windows.

02

CI/CD Re-Architecture

Modernized heterogeneous deployment pipelines into reusable GitHub Actions workflows with externalized .config files spanning DEV, SIT, QA, and PROD stages across AU & NZ clusters.

03

Zero-Trust GKE Delivery

Eliminated long-lived service account JSON keys by configuring GCP Workload Identity federation with CDAP authentication. Multi-microservice rollouts verified via automated health probe validation.
