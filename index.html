02 / Architecture Case Study

600+ Repo GHES → GHEC Cloud Modernization
Banking Scale

The Operational Challenge

ANZ's engineering squads operated across on-premises GitHub Enterprise Server instances with fragmented deployment scripts (Codefresh, uDeploy) and manual gating. Transitioning 600+ repositories into GitHub Enterprise Cloud required strict zero-downtime execution, cryptographic commit history preservation, and immediate compliance with bank-wide security standards.

01. Pre-Flight Auditing

Programmed automated Bash and REST API crawlers to inventory repo sizes, LFS assets, branch protections, and webhook dependencies. Generated automated delta reports prior to maintenance windows.

02. Pipeline Standardization

Replaced heterogeneous deployment scripts with reusable GitHub Actions composite workflows. Externalized environment configurations (.config) across DEV, SIT, QA, and PROD clusters.

03. Zero-Trust GKE Delivery

Eliminated long-lived service account JSON keys by configuring GCP Workload Identity federation with CDAP authentication. Multi-microservice rollouts verified via automated health probe validation.
